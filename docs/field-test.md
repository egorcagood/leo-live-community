# Проверка перед первым аппаратным релизом

Эта процедура подготовлена; прохождение на настоящем автомобиле пока не подтверждено. Заполняй только фактические результаты, не публикуй VIN, госномер, адрес адаптера или личные логи.

## Дома, без автомобиля

- Записать версию APK, SHA-256 и Android.
- Установить как отдельный пакет Community; частный LEO Live не удалять.
- Запустить demo без выдачи разрешений. Проверить заметную метку DEMO, меняющиеся числа и вымышленный P0171.
- Экспортировать CSV. В строках только DEMO, данные соответствуют экрану.
- Свернуть/заблокировать телефон: demo останавливается. После возврата старые числа не показываются как текущие.
- Закрыть и открыть приложение: предыдущий журнал доступен для экспорта; новая сессия требует осознанной замены.
- Отказать в Bluetooth-разрешении: приложение объясняет ситуацию, demo остаётся доступным.

## На стоянке

- Записать модель/прошивку адаптера, год/двигатель автомобиля и Android без идентифицирующих данных.
- Припарковаться, включить зажигание, закрыть другие OBD-приложения. Выбрать свой адаптер.
- Дождаться определения совместимости. Отдельно отметить каждый показанный PID и каждую недоступную карточку.
- Сверить RPM и ОЖ с независимым прибором/известным диагностическим чтением. Не считать точность доказанной только совпадением одной цифры.
- При заглушённом двигателе проверить, что корректный ноль RPM отличается от отсутствия ответа.
- По кнопке прочитать engine stored/pending DTC. Не создавать неисправности специально. Не делать выводов о SRS/ABS по этому результату.
- Отключить адаптер: приложение прекращает запросы, убирает текущие числа, не переподключается самостоятельно.
- Подключиться вручную ещё раз: никакие показания прошлого сеанса не попадают в новый.
- Свернуть приложение и открыть снова: соединение остановлено. Экспортировать CSV, убедиться в источнике OBD.
- Если приборы/адаптер ведут себя необычно, прекратить тест. Не подбирать OEM-команды и не изменять проводку ради Community.
