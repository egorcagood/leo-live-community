# Этапы Community

## 1. Локальный preview - текущий кандидат

Один Android APK: demo, поддерживаемые стандартные OBD-показатели, чтение engine DTC, частный журнал и CSV. Следующий барьер - ручная проверка на реальном адаптере, затем согласование публичного текста, лицензии и подписанного релиза.

## 2. Надёжная локальная версия

Проверки Android 8/11/12/16, жизненного цикла и разрешений, автоматизированный BLE fake transport, расширение таблицы подтверждённого оборудования. Отдельно - фоновая запись с foreground service и проверкой энергосбережения. Каждый новый формат ответа получает тест на реальном обезличенном примере с разрешением владельца.

## 3. Self-hosted сервер с BYOK - пока не реализован

Один Android-клиент с явным выбором «Только локально / Мой сервер». В настройках - HTTPS URL и вход в свой аккаунт. Ключ AI-провайдера вводится только в серверной панели и хранится зашифрованным на сервере. APK получает токен пользователя, не ключ провайдера. Должны появиться Docker Compose, миграции, health checks, backup/restore и инструкция обновления.

Предлагаемая серверная конфигурация: `PUBLIC_BASE_URL`, `DATABASE_URL`, путь к ключу шифрования, allowlist AI-провайдеров, ограничения бюджета/частоты, необязательный Telegram bot token через секрет-файл. Это проект схемы, не работающие переменные текущего приложения.

Каждый объект принадлежит пользователю и автомобилю. Авторизация проверяется на каждом чтении/изменении, включая экспорт, голос и фоновые задачи. Тесты должны запрещать доступ пользователя A к данным B. Телеметрия хранится детерминированно; платный AI не запускается на каждый замер. Бюджет резервируется атомарно до запроса и сверяется с фактическим usage. Лимиты сессии/суток и частоты обязательны. Нет неограниченного fallback на более дорогую модель.

Telegram - отдельный добровольно включаемый модуль с подтверждённой привязкой получателя. Локальный режим сохраняется при отсутствии сервера и ключей. Передача истории/местоположения только с opt-in и возможностью удаления.

## 4. Voice

Сначала стабильная доставка проверенных показаний, затем разговор. Характер не меняет происхождение, свежесть или смысл измерений. Голос не получает права отправлять произвольные команды автомобилю. Перед релизом: разрывы сети, аудио, отмена, расход, работа при сворачивании и предотвращение двойных платных сессий.

## 5. Добровольная интеграция с LEO Auto

Отдельный опубликованный API-контракт, scoped tokens, явный выбор автомобиля и состава истории, отзыв доступа и удаление. Live и Auto не считаются уже полностью интегрированными. Production-сервисы не изменяются ради установки Community. Hosted-режим не должен быть необходим для demo или локального OBD.
