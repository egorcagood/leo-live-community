# Совместимость и границы проверки

Это предварительная версия. Не покупай адаптер только на основании этого списка до появления отчёта о проверке именно Community.

| Компонент | Реализовано | Подтверждение |
|---|---|---|
| Android 8+ (API 26), Java API с учётом minSdk | Да | Сборка и lint; не весь диапазон устройств проверен |
| Offline demo | Да | Проверки ядра; Android-проверки отмечаются в release report |
| vLinker FD+ BLE с GATT 18f0/2af1/2af0 | Контроллер реализован | Новая Community-сборка ещё не прошла проверку на машине |
| Другие BLE-профили, Bluetooth Classic, Wi-Fi, USB | Нет | Неподдерживаемое подключение |
| Стандартные RPM/скорость/ОЖ/нагрузка/дроссель/топливо %/напряжение ЭБУ | Только после карты поддержки | Нужен ответ конкретного автомобиля |
| Engine stored/pending DTC | Ограниченный парсер 03/07 | Не чтение всех блоков автомобиля |
| Литры, одометр, SRS, ABS, передача, OEM-диагностика | Нет | Не обещать доступность |

Результаты частного LEO Live не являются проверкой этого отдельного приложения. Не переносим в публичный выпуск чужие базы диагностических определений и частные захваты.

## Что означает «недоступно»

PID не объявлен, блок не ответил, формат неизвестен или несколько ответов противоречат друг другу. Это не неисправность само по себе. `0 rpm` при корректном ответе - настоящее нулевое значение; отсутствие ответа - не ноль.

Показатель топлива `012F` - проценты по ЭБУ. Приложение не умножает их на выдуманную ёмкость бака. Напряжение `0142` - напряжение модуля управления, а не гарантированно точное измерение клемм АКБ.

## Как сообщить о проверке

Укажи версию Community, Android, модель/версию прошивки адаптера, год/двигатель автомобиля без VIN. Опиши, какие карточки показали значения, какие - недоступность, удалось ли отключиться и подключиться снова. CSV отправляй только после просмотра и удаления личной информации. Не прикладывай историю поездок или документы автомобиля.

Перед первым тестом припаркуй машину. Проверь связь, корректную остановку и отсутствие необычного поведения приборов. При неожиданном поведении прекрати сеанс и отсоедини адаптер. Приложение не заменяет диагностику специалистом и не подтверждает безопасность автомобиля отсутствием engine DTC.
