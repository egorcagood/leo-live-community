# Подготовка публикации

Владелец разрешил публикацию 0.1.0-preview.1 как раннего предрелиза исходников без аппаратной проверки. APK в него не включён. Для следующих выпусков ниже остаётся процедура проверки.

## Обязательные шаги

1. Прочитать README, quick-start, compatibility и текст анонса. Подтвердить название, лицензию Apache-2.0, автора и содержание. Не обещать голос или сервер в первом выпуске.
2. Выполнить тесты ядра, Python, Android build/lint и `scripts/release-audit.py`. Проверить полный список `release-files.txt` и отчёт SHA-256. Исключить персональные данные, ключи, старую историю Git и локальные сборки.
3. Проверить demo, остановку/возврат, экспорт и восстановление журнала на обычном Android-устройстве. Проверить BLE на припаркованном автомобиле; записать версии приложения/Android/адаптера, поддерживаемые PID и фактический результат. До этого - только source preview с явным статусом непроверенного оборудования.
4. Создать отдельный публичный GitHub-репозиторий только после согласования. Использовать новую историю, а не fork/private remote. Первый commit содержит исключительно проверенный список файлов. Убедиться, что не включены `.private`, `.git`, build, APK, local.properties, captures и секреты.
5. Включить private vulnerability reporting, защиту основной ветки, обязательные проверки PR и запрет force-push. Проверить CI в новом репозитории. GitHub CI пока не запускался: локальные результаты его не заменяют.
6. Для бинарного релиза создать отдельный Community signing key вне репозитория, сохранить резервную копию. Никогда не переиспользовать production-ключи. Выпустить подписанный release APK, проверить сертификат, manifest, SHA-256 и установку/обновление. Локальный debug APK - только для теста, не официальный релиз.
7. Опубликовать notes с точной матрицей совместимости, ограничениями, хешами и исходным commit. Проверить скачивание и сборку из чистого архива.

Ручная процедура: [полевой тест](field-test.md).

## Локальный пакет на просмотр

```sh
python3 scripts/release-audit.py --archive
```

Скрипт проверяет allowlist и создаёт `.private/dist/community-source-preview.zip` с `SHA256SUMS` внутри. Не включает Git, APK, журналы, SDK или документы локальной проверки. Архив не заменяет просмотр владельцем и не отправляется в сеть.

После любой правки публичного текста или кода пересобрать архив и повторить проверки. Не выполнять `git add .` в родительском частном проекте. Никаких автоматических deploy, GitHub release или установки на телефон.
