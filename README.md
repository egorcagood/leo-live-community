# LEO Live Community

Всем привет! Это открытая часть моего проекта LEO: приложение для Android, которое читает показания машины через BLE OBD-адаптер и сохраняет их на телефоне.

В личном LEO я уже экспериментирую с голосом, историей обслуживания и помощью в ремонте. Community начинаю с основы: подключение, показания, журнал и demo без машины. Голос, Telegram, AI и сервер в этот первый выпуск пока не входят.

**0.1.0-preview.1: ранний предрелиз исходников.** Тесты и сборка проходят, demo проверен на эмуляторе. Именно эту Community-сборку на настоящей машине ещё не проверяли. То, что работало в личном LEO, не означает автоматическую поддержку здесь.

**Для iPhone приложения пока нет.** iOS потребует отдельной разработки. Сейчас в репозитории только Android.

## Хочу попробовать. С чего начать?

Без машины тоже можно. Собери приложение по [инструкции](docs/android-setup.md), открой его и нажми **Попробовать без машины**. Увидишь вымышленные показания с заметной меткой DEMO. Bluetooth, аккаунт и API-ключ для этого не нужны.

Если хочешь подключить машину, начни с [инструкции подключения](docs/quick-start.md). Там по шагам: адаптер, разрешения, кнопки, журнал и что делать, если не получилось.

Готового подписанного APK для обычной установки в этом source preview нет. Исходники можно скачать со страницы предрелиза и собрать самому.

## Что уже есть

- Demo без автомобиля и интернета.
- Поиск BLE-адаптеров и выбор своего устройства.
- Проверка профиля vLinker FD+ и поддерживаемых машиной стандартных показателей.
- Обороты, скорость, температура ОЖ, нагрузка, дроссель, топливо в процентах и напряжение ЭБУ, если автомобиль их отдаёт.
- Чтение сохранённых и ожидающих ошибок двигателя по кнопке.
- Последний журнал в памяти приложения и экспорт в CSV.

Если показателя нет, приложение его не придумывает. «Прочитать не удалось» не превращается в «ошибок нет». Ошибки не стираем, блоки не программируем, произвольные команды отправить нельзя.

## Что пока не стоит ждать

SRS, ABS, коробка, передача, одометр и литры топлива здесь пока не читаются. Показатель топлива в процентах тоже доступен не на каждой машине. Bluetooth Classic, Wi-Fi и USB-адаптеры не поддерживаются: пока только описанный BLE-профиль.

**Свернул приложение или погасил экран? Запись и связь остановятся.** Это относится и к переходу в выбор файла при экспорте. После возврата подключись заново. Фоновую работу надо делать отдельно, сейчас её нет.

Новая сессия заменяет предыдущий журнал. Если хочешь его оставить, сначала сохрани CSV. В журнал помещаются последние 10 000 строк.

## Куда уходят данные?

Автоматически никуда. У приложения вообще нет разрешения на интернет. Координаты, VIN и разговоры оно не собирает. Адрес Bluetooth нужен только для выбора адаптера на экране и в CSV не попадает.

Сам решаешь, куда сохранить файл. Если выберешь облачный диск в системном окне Android, он может загрузить файл в своё облако. Это уже выбранное тобой приложение для файлов.

## Что нужно для машины

Android 8.0 или новее, BLE-адаптер с нужным профилем и автомобиль с подходящими стандартными OBD-функциями. Начинаем с vLinker FD+, но аппаратный тест новой сборки ещё впереди. Не покупай адаптер только по этому списку, сначала проверь [совместимость и ограничения](docs/compatibility.md).

Первый раз подключайся на стоянке с включённым зажиганием. Одинаковый разъём ещё не значит, что все машины отдают одинаковые данные.

## Хочешь покопаться в коде?

Я один не сделаю универсальный вариант под каждую машину. Если хочется разобраться или помочь с проверками, вот основные документы:

- [Как это работает](docs/how-it-works.md).
- [Сборка Android](docs/android-setup.md).
- [Проверка на телефоне и машине](docs/field-test.md).
- [Что планируется дальше](docs/roadmap.md).
- [Как предложить изменение](CONTRIBUTING.md).
- [Как сообщить об уязвимости](SECURITY.md).

Проверки из корня проекта:

```sh
sh scripts/test-core.sh
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/release-audit.py
cd android
./gradlew :app:assembleDebug :app:lintDebug
```

Они не отправляют запросы машине и не вызывают платный AI. Успешные тесты не заменяют проверку на настоящем адаптере.
